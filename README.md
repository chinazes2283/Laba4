# Лабораторна робота №4

Тема: створення графічного користувацького інтерфейсу з використанням PyQt6.

## Структура

```
.
├── lb4t1.py           # Завдання 1: базові віджети та layouts
├── lb4t2.py           # Завдання 2: інтерактивна форма, сигнали та слоти
├── lb4t3.py           # Завдання 3: QMainWindow, меню, toolbar, statusBar
├── lb4t4.py           # Завдання 4: кастомні сигнали, міжкомпонентна взаємодія
├── lb4t5.py           # Завдання 5: діалогові вікна та QSS-стилізація
├── text1.txt          # Тестовий файл для відкриття через діалог
├── requirements.txt
├── README.md
└── .gitignore
```

## Вимоги

- Python 3.10+
- PyQt6

## Встановлення

```bash
pip install -r requirements.txt
```

Рекомендовано використовувати віртуальне середовище:

```bash
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Linux / macOS
pip install -r requirements.txt
```

## Запуск

Кожне завдання запускається окремо з кореня проєкту:

```bash
python lb4t1.py
python lb4t2.py
python lb4t3.py
python lb4t4.py
python lb4t5.py
```
